La red física mas extendida del mundo es la red telefónica, mediante señales analógicas

TDM: multiplexado por división de tiempo.
$T_s = N·T_M$
Para poder evaluar ciertas muestras, no alcanza solo con analizar el dominio del tiempo. Tampoco podemos reconocer una sinusoide solo con este dominio, por eso necesitamos analizar el dominio frecuencial.

Espectro de un tren de pulsos (no periódico): función $sinc$ $x$.
No hay relación entre el espectro y el tiempo. No hay correlación ya que son dominios distintos.

Teorema del muestreo
Limite para la frec. De muestreo: $f_s$ mayor o igual a $2·f_{max}$

Determina: Cual es el mínimo de la frec. de muestreo que puedo tener sin que se pierda la señal

$T_M= n·tau$
Entonces $T_s = N·n·tau$

El ancho de banda del canal...

$T_s = N·n·tau = 1/ f_s = 1/2·f_{max} = N·n·1/BW$

$BW = N·n·2·f_{max}$

Se usan los Time Slots

Gran diferencia entre TDM y FDM: cantidad de digitos con los que se codifican las muestras ($n$). Si aparece esta variable, se trata de TDM, sino se trata de FDM. 
- Modulacion AM - Multiplex. FDM
- Modulación PCM - Multiplex. TDM
Si consideramos "muestras", hablamos de TDM. Estas no existen en FDM.
