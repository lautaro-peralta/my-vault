#### Sistemas Multinivel

##### *FSK Multinivel*

|Símbolo|Bits|Frecuencia-Amplitud|
|---|---|---|
|A₁f₁|00|Amplitud 1, Freq 1|
|A₂f₁|11|Amplitud 2, Freq 1|
|A₁f₂|01|Amplitud 1, Freq 2|
|A₂f₂|10|Amplitud 2, Freq 2|

**Ejemplos**: 8-FSK, 16-FSK, 32-FSK

##### *PSK Multinivel*

- **Representación**: Diagrama polar (constelación)
- **Ejemplos**: 8-PSK, 16-PSK, 32-PSK
- **Ventaja**: Mayor eficiencia espectral

##### *QAM (Quadrature Amplitude Modulation)*

- **Característica**: Rotación de 45° para optimizar coordenadas
- **Principio**: Combina modulación de amplitud y fase
- **Ventaja**: Máxima eficiencia espectral para un nivel de ruido dado
